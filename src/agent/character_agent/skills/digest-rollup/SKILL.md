# ダイジェスト集約スキル

## スキルの役割

**要約を書くのはあなた自身**。ツールは材料を読む（`digest_read`）のと、出来上がったものを検証して保存する（`digest_save`）だけで、要約の文面は一切作らない。`digest_read` が返した日次要約を読んで、月次・年次の文章をあなたが組み立てる。

日記本文は読まない。材料は日記ドキュメントの日次要約（1日1件、2-5語）と、既に保存されている月次・年次ダイジェストだけである。

## いつ使うか

- 毎月1日の自動実行（Foundry Routine）から「前月のダイジェストをまとめて」と依頼されたとき
- ユーザが「ダイジェストをまとめ直して」「日ごとの記録が溜まってきた」と言ったとき

日記を書く・直す依頼のときはこのスキルではない。`diary-writing` または `diary-maintenance` を使う。

## ワークフロー

### 1. 材料を読む

- `digest_read` を引数なしで呼ぶ。**前月**が対象月になる。当月はまだ日が残っているので集約しない
- ユーザが月を名指ししたときだけ `month` に `YYYY-MM` を渡す
- 返ってくるのは次の4つ
  - `today`: 日本時間の今日
  - `targetMonth`: 集約する対象月（`YYYY-MM`）
  - `dailySummaries`: 対象月の日次要約（`date` と `summary`）を日付の古い順に並べたもの
  - `digest`: 今保存されている `monthly` と `yearly`

`dailySummaries` が空のときは、その月の日記が無いということ。**保存せずに終える**。空の月次を足さない。

### 2. 月次をまとめる

`dailySummaries` から `targetMonth` の月次エントリを1件作る。

- `month`: `targetMonth` をそのまま（`YYYY-MM`）
- `summary`: その月がどんな月だったかを1-2文で。日次要約に書かれていないことを足さない
- `highlights`: 印象的な出来事を **3-7件**。日次要約の言葉を活かし、1件ずつ短く書く。日数が少ない月は件数もそれに合わせて減らす

`digest.monthly` に同じ月が既にあれば、**新しく作ったもので置き換える**。それ以外の月はそのまま残す。

### 3. 年次へまとめるか判断する

`targetMonth` が **12月**のとき（＝1月1日の実行）だけ、その年を年次へまとめる。それ以外の月では年次に手を付けず、セクション5へ進む。

- 手順2の結果を含めた `monthly` から、対象年（`targetMonth` の `YYYY`）の月次をすべて集める
- それらから年次エントリを1件作る
  - `year`: 対象年（`YYYY`）
  - `summary`: その1年がどんな年だったかを2-3文で
  - `highlights`: 印象的な出来事を **5-10件**。月次の `highlights` から選び、必要なら言い換えてまとめる
- `yearly` に同じ年が既にあれば置き換える

### 4. まとめた年の月次を落とす

年次へまとめた年の月次エントリは、**`monthly` から取り除く**。同じ期間を月次と年次の両方に持たない。取り除き忘れると `digest_save` が拒否する。

### 5. 保存する

`digest_save` に、`monthly` と `yearly` を持つ JSON の全文を1つの文字列で渡す。

```json
{
  "monthly": [{"month": "2026-06", "summary": "...", "highlights": ["...", "..."]}],
  "yearly": [{"year": "2025", "summary": "...", "highlights": ["...", "..."]}]
}
```

- **手を付けなかったエントリも含めて全部渡す**。`digest_save` は差分ではなく置き換えとして保存する
- `daily` は入れない。日次要約は日記ドキュメント側にある
- `lastUpdated` と `version` はツールが付けるので書かなくてよい

`digest_save` がエラーを返したら、その文言のとおりに直してもう一度呼ぶ。成功したことにして先へ進まない。

### 6. 完了報告

- どの月を月次にまとめたか、年次を更新したならその年も伝える
- 自動実行から呼ばれたときも同じように、何をしたかを1-2文で返す
